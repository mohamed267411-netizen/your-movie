# 🎬 Your Movies | منصة الأفلام والمسلسلات والأنمي

منصة ويب متكاملة، متجاوبة وعصرية لاستعراض ترشيحات وتفاصيل أفضل الأفلام والمسلسلات والأنمي مع التقييمات، قصص الأعمال، وطاقم العمل والمخرجين.

---

## 🌟 المميزات الرئيسية (Key Features)

### 1. الصفحة الرئيسية (Home Page - `html/home.html`)
- **سلايدرات تمرير أفقي سلسة (Horizontal Scroll Sliders):** تمكين التمرير يميناً ويساراً بواسطة أسهم التحكم لكل من أقسام الأفلام، والمسلسلات، والأنمي دون إعادة تحميل أو فتح صفحات جديدة.
- **قائمة ميجا منيو احترافية (Mega Menu):** متناسقة مع عرض شريط التنقل وتضم صوراً متغيرة تلقائياً كل 2.5 ثانية تجمع لقطات متنوعة من أقسام الموقع الثلاثة (أفلام، مسلسلات، أنمي) مع روابط تنقل وشبكات تواصل.

### 2. صفحات الأفلام (Movies Section)
- تشمل 5 تصنيفات فرعية: **الكل** (`movies-all.html`)، **عربي** (`movies-arab.html`)، **أجنبي** (`movies-foreign.html`)، **كوميدي** (`movies-comdy.html`)، **أكشن** (`movies.action.html`).
- **نظام نافذة منبثقة سينمائي (Lightbox Modal):** عند النقر على أي فيلم أو علامة (+)، تظهر نافذة تفاصيل أنيقة في منتصف الشاشة مع خلفية معتمة ببلور زجاجي (`backdrop-filter`) تعرض قصة الفيلم والمخرج وطاقم الممثلين.
- **إمكانية الإغلاق السلس:** بالنقر على زر الإغلاق (X)، أو بالنقر في أي مكان خارج النافذة، أو بالضغط على زر `Escape` من لوحة المفاتيح.
- شبكة كروت متجاوبة بالكامل بنظام CSS Grid تتكيف تلقائياً مع الهواتف والتابلت والشاشات الكبيرة.

### 3. صفحات المسلسلات (Series Section)
- تشمل 5 أقسام: **Top 8** (`Top10.html`)، **عربي** (`arabic.html`)، **أمريكي** (`USA.html`)، **تركي** (`turkish.html`)، **بريطاني** (`britsh.html`).
- **سلايدر ثلاثي الأبعاد تفاعلي (3D Flip Card Slider):** تصميم كروت مجسمة تعرض تفاصيل كل مسلسل وقصته بدقة وأناقة مع أزرار تنقل تفاعلية.

### 4. صفحات الأنمي (Anime Section)
- تشمل الصفحة الرئيسية للأنمي (`pro.html`)، وصفحة الأنمي الأكثر شعبية (`most.html`)، وصفحة الأنمي المستمر (`continuous.html`).
- نظام نوافذ تفاصيل متجاوب وإمكانية تصفح موسعة.

### 5. صفحة تواصل معنا (Contact Page - `html/contact.html`)
- نموذج مراسلة متجاوب 100% بنظام ثيم داكن فخم متطابق مع ألوان الموقع.
- تثبيت الفوتر أسفل الشاشة (Sticky Footer) عبر Flexbox لتجنب الفراغات أو انكسار المظهر.

### 6. شريط تنقل علوي موحد (Site Header)
- شريط مثبت في أعلى الشاشات (`position: sticky; top: 0`) مع خلفية زجاجية نصف شفافة.
- شعار الموقع (Logo) في اليسار ينقلك للرئيسية فوراً.
- أزرار التنقل متوسطة بدقة في المنتصف: **Home** | **Movies** | **Series** | **Anime** | **Contact**.

### 7. فوتر مدمج ومتناسق (Unified Footer)
- فوتر موحد ومطابق في كافة صفحات الموقع الـ 15 مقسم إلى 3 أعمدة (معلومات الموقع وشبكات التواصل، الروابط السريعة، وأقسام الموقع) مع زر العودة للأعلى (Back to Top).

## 🛠️ التقنيات المستخدمة (Technologies)

- **HTML5:** بناء هيكلي نظيف ووسوم دلالية معتمدة (Semantic Elements).
- **CSS3:**
  - CSS Variables لتوحيد لوحة الألوان (`#222831`, `#31363F`, `#76ABAE`, `#EEEEEE`).
  - CSS Flexbox & CSS Grid للتجاوب الكامل على جميع أحجام الشاشات.
  - 3D Transforms & Keyframe Animations لتأثيرات بصرية مميزة.
- **Vanilla JavaScript (ES6+):** أكواد خفيفة وسريعة بدون أي مكتبات خارجية ثقيلة.
- **Font Awesome 6:** أيقونات عصرية لمختلف الأقسام والتفاعلات.
- **Google Fonts:** خطوط أنيقة ومتناسقة (*Cairo*, *Work Sans*, *Open Sans*).
